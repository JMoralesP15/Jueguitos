# Seguridad

No publiques vulnerabilidades en issues públicos.

Mientras el proyecto no tenga un canal de seguridad externo, registra el hallazgo como un borrador privado de GitHub Security Advisory. Incluye impacto, pasos de reproducción, datos afectados y una propuesta de mitigación si está disponible.

Los secretos expuestos deben revocarse inmediatamente, incluso si el commit fue eliminado del historial visible.
